# Andrea Liss Boutique

Site institucional e catálogo online da Andrea Liss Boutique, localizada em Samambaia Norte, Brasília–DF.

## Tecnologias

- React 19
- TanStack Start
- TypeScript
- Tailwind CSS
- Vite

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Compilação

```bash
npm run build
```

## Publicação

O projeto é compatível com Vercel por meio do suporte a TanStack Start e Nitro. Conecte o repositório GitHub à Vercel e mantenha as configurações automáticas de framework, build e saída.
